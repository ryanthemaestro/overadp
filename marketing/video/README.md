# OverADP campaign videos

`overadp-adp-vs-model-voiceover.mp4` is a silent 16:9 H.264 cut built from real OverADP screens. Browser chrome and unrelated tabs are cropped out.

`overadp-adp-vs-model-final.mp4` is the finished narrated version with cleaned voice audio, retimed scenes, burned-in captions, the study-scope disclosure, and the $6.99 offer.

- Silent cut: about 66 seconds
- Narrated cut: about 83 seconds
- Resolution: 1920×1080
- Original voiceover: use `voiceover-script.md`
- Original captions: `overadp-voiceover.srt`
- Narrated captions: `overadp-voiced.srt`
- Record narration locally: open `recorder.html` from a localhost web server
- Rebuild silent cut: run `./render.sh`
- Rebuild narrated cut: run `./render-voiced.sh`; its seven named WebM takes are preserved in `recordings/`

The historical-result language is intentionally qualified. It says the retrospective simulation found stronger drafted rosters; it does not promise championships or future results.
